# Sistem belajar Inggris — 26 minggu dari dasar

Panduan berbahasa Indonesia untuk mulai dari nol, memakai **engVid sebagai bank penjelasan utama**, lalu latihan dengar, baca, bicara, tulis, pengulangan, dan feedback. Riset dilakukan 31 Oktober 2026. Tidak perlu memilih puluhan aplikasi sebelum mulai.

## Buka website

**https://rahmadnoorikhsan.github.io/EnglishCourse/**

Website memakai alur kelas **Pola & contoh → dengar & baca → bicara & tulis → review**. Setiap hari menampilkan judul, target, dan alur fokus satu minggu. Penjelasan Indonesia, contoh bilingual, kosakata, bacaan, audio, kuis, dan tugas mengikuti hari yang dipilih. Setiap hari aktif memiliki video pembelajaran berbeda: **156 video untuk 26 minggu × 6 hari**, dengan fokus menonton dan tugas penerapan berbahasa Indonesia. Hari 1–5 menampilkan video pada langkah pertama; video hari 6 tersedia pada **Ulangi & evaluasi**, setelah pengerjaan evaluasi. Hari 7 tetap istirahat. Player menghubungi YouTube/Google hanya setelah diklik. Transkrip listening tetap terlipat sebelum dicoba. Progres dan catatan tetap lokal.

Navigasi kelas tidak lagi memakai dropdown minggu/hari. Sidebar menampilkan judul minggu utuh, panah minggu sebelumnya/berikutnya, dan tombol hari 1–7 dengan penanda hari aktif serta titik ketika empat langkah ditandai selesai. **Ganti minggu** membuka dialog 26 minggu yang dikelompokkan per fase, berisi judul topik dan jumlah langkah yang ditandai (bukan skor). Pilih minggu untuk membuka hari 1; memilih hari membuka langkah pertama yang belum selesai. Escape atau tombol tutup mengembalikan fokus ke pemicu; Back/Forward dan tautan langsung tetap digunakan. Pada HP, buka **Daftar langkah** untuk navigasi ini.

Visual terinspirasi Solana: hitam pekat, tipografi besar, tombol pill putih, dan aksen ungu–hijau pada kartu video. Navigasi utama di atas dan area materi/video tetap lebar di laptop. Di HP/tablet, kelas menjadi satu kolom dan **Daftar langkah** bisa dilipat; judul video memiliki panel gelap agar tetap terbaca. Tampilan cetak tetap terang. Tidak ada integrasi wallet atau blockchain.

Navigasi pendukung (silabus, sumber, evaluasi, kembali ke referensi, dan footer) memakai kontrol berbingkai dengan area klik minimal 44 px, bukan link teks kecil bergaris bawah. Link di dalam isi dokumen tetap tampil sebagai tautan bacaan.

Checklist dan catatan lama tetap digunakan dan dimigrasikan otomatis. Progres disimpan **hanya di browser/perangkat yang sama**; tidak tersinkron atau terkirim ke GitHub. Ekspor JSON dari Progres untuk arsip. JSON memuat riwayat hasil, waktu, tulisan, rubrik, dan referensi audio, **bukan file audio**; unduh audio satu per satu dari portofolio. JSON adalah arsip, bukan fitur impor kembali. Menghapus data browser menghapus progres dan audio lokal; jangan masukkan informasi sensitif. Tombol selesai mencatat aktivitas, bukan nilai atau kelulusan CEFR.

Sumber Markdown di repository tetap menjadi sumber kurikulum/referensi. Paket materi asli di `src/course-*.js` melengkapi kurikulum dengan teks dan soal lokal, bukan salinan pelajaran pihak ketiga. Catatan harian lama tetap tersedia (maksimal 5.000 karakter). Pada **Bicara & tulis**, panel **Latihan bicara langsung** menjadi alur utama: rekam mikrofon, putar ulang, dan minta koreksi harian tanpa memilih berkas. Portofolio menulis dan arsip manual berada dalam panel opsional terlipat; audio manual tetap lokal (maksimal 15 MiB). Panel AI pada langkah **Review** menangani tugas mingguan/fase terpisah. Teks/audio AI (maksimal 10 MiB) hanya dikirim setelah persetujuan eksplisit, melalui backend pribadi lalu 9router. Jangan kirim data sensitif atau suara orang lain tanpa izin.

## Target yang jujur

**Enam bulan bukan jaminan professional & academic fluency menyeluruh atau C1.** Acuan Cambridge memperkirakan 500–600 jam terbimbing dari pemula ke B2 dan 700–800 ke C1; jam mandiri tidak otomatis setara. Default program ini 3 jam fokus × 6 hari × 26 minggu = **468 jam rencana**, bukan hasil yang sudah dicapai.

Keputusan: kejar kemampuan yang bisa dibuktikan—perkenalan dan percakapan dasar → pesan/email dan penjelasan terhubung → rapat/presentasi → memahami sumber dan menulis argumen. B1 menjadi orientasi antara latihan; B2 sasaran ambisius yang harus diuji; C1 tetap tujuan lanjut jika belum terbukti. Level tidak ditetapkan dari jumlah video atau bulan belajar.

Penjelasan bukti, asumsi, dan batasannya: [01-RISET.md](01-RISET.md). Ini sistem latihan personal, bukan pengganti persyaratan bahasa universitas/pekerjaan atau program ujian resmi.

## Mulai hari ini

1. Pilih waktu fokus realistis: 60, 120, 180, atau 240 menit per hari belajar. Ada konsekuensi terhadap target dan kemungkinan durasi program; lihat sistem harian.
2. Siapkan alat rekam bawaan HP/laptop, catatan, dan kartu kertas atau Anki. Tidak wajib tutor berbayar, akun tes, atau langganan AI.
3. Buka **[Belajar](https://rahmadnoorikhsan.github.io/EnglishCourse/belajar/)**. Mulai dari Minggu 1, Hari 1; jalankan tugas lalu pilih **Selesai & lanjut**. Tidak perlu membuka semua materi sekaligus.
4. Rekam perkenalan sebisanya **sebelum meniru**. Jika belum bisa, tulis “belum bisa”—itu baseline, bukan kegagalan.
5. Gunakan [VOA Lesson 1](https://learningenglish.voanews.com/a/lets-learn-english-lesson-one/3111026.html) dan bagian pendek [engVid: TO BE](https://www.engvid.com/basic-english-grammar-to-be/). Hasil hari 1: tiga kalimat tentang diri dan satu rekaman pendek setelah latihan.
6. Catat menit nyata dan hasil di tracker. Jika hari pertama hanya tersedia 20 menit, lakukan versi darurat di sistem harian; jangan mencatatnya sebagai tiga jam.

Jika penjelasan engVid masih tidak dipahami, gunakan dialog VOA + arti Indonesia terlebih dahulu. Fondasi tidak harus diawali dengan memahami ceramah bahasa Inggris penuh.

## Pengembangan lokal

Node.js 22 dan npm 10.9.2. Jalankan dari folder repository:

```sh
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1
```

Pemeriksaan dan preview produksi:

```sh
npm run check
npm test
npm run check:course
npm audit --audit-level=high
npm run build
npm run preview -- --host 127.0.0.1
```

Stack: Vite, JavaScript modul, marked, DOMPurify. `src/content.js` membaca enam dokumen asli, `src/lesson.js` dan `src/material.js` menampilkan kelas/materi lokal, `src/quiz.js` memeriksa soal, `src/views.js` menampilkan halaman pendukung, `src/state.js` mengelola progres lokal. `src/router.js` memetakan URL bersih; History API menangani navigasi, Back/Forward, dan posisi gulir tanpa reload halaman. `scripts/build-routes.mjs` membuat index HTML untuk semua rute valid agar direct URL/refresh pada GitHub Pages merespons 200, tanpa redirect 404. `dist/` dan `node_modules/` tidak di-commit. `.npmrc` memblokir lifecycle scripts dependency.

## Materi, audio, dan batas penilaian

- Seluruh 26 minggu memiliki lima pelajaran harian bertahap dan satu evaluasi: 130 paket latihan + 26 paket evaluasi. Hari 1–5 memakai penjelasan, contoh, kosakata, bacaan, audio, kuis, dan tugas berbeda. Hari 6 mempertahankan bacaan/audio evaluasi terpisah; hari 7 istirahat. Mengulang sebuah hari bukan materi baru.
- MP3 lokal memakai **Kokoro neural TTS v1.0, American English**. Pemeran dialog eksplisit pada `cast` tiap paket harian; pemeran evaluasi di `scripts/audio-cast.json`. Giliran memakai suara berbeda dengan jeda 300 ms, tanpa membacakan label. Kecepatan 0,85× minggu 1–4, 0,93× minggu 5–13, dan 1× minggu 14–26. Semua situasi/data fiktif; audio AI bukan rekaman manusia atau tes terstandar. TTS dapat salah melafalkan nama/istilah; tiap pelafalan belum diaudit manusia. [Dokumentasi suara dan keterbatasan](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md).
- Riwayat kuis harian memakai identitas minggu/hari/jenis; mengulang hari yang sama tercatat familier. Riwayat paket mingguan lama tidak dihapus. Identitas listening/reading evaluasi lama tetap dipakai karena teksnya tidak berubah, sehingga tidak tiba-tiba dianggap baru. Checklist lama tetap catatan aktivitas, bukan bukti telah menguasai materi baru. Hasil lokal bukan CEFR terverifikasi.
- Video pengajaran dari engVid dan sumber pendidikan lain memakai player YouTube resmi, tanpa mengunduh/menyalin/mengubah videonya. Player dimuat setelah kartu video ditekan; saat itu browser menghubungi YouTube/Google. Embed memerlukan internet dan dapat dibatasi penyedia, wilayah, atau browser. Tautan **Sumber asli** dan **YouTube** tersedia di samping player. Fokus menonton dan latihan lokal dilabeli sebagai pendamping buatan EnglishCourse, bukan materi/kuis resmi sumber. [Dokumentasi embed](https://developers.google.com/youtube/player_parameters).
- Materi British Council, Purdue, atau situs lain tidak disalin massal. Tautan pada Referensi adalah sumber tambahan, bukan prasyarat menuntaskan latihan lokal. Tidak ada klaim bahwa kuis lokal setara dengan asesmen sumber tersebut.

[Rilis model resmi](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.1). ## Catatan perubahan: bukti belajar dan evaluasi

- **Waktu fokus:** pilih keterampilan lalu mulai/jeda timer. Timer menyimpan saat dijeda, pindah halaman, atau tab disembunyikan; tidak menghitung tab latar. Waktu di luar timer dapat dicatat manual 1–480 menit. Jangan menghitung kegiatan yang sama dua kali. Progres menampilkan waktu nyata per keterampilan, terpisah dari durasi rencana/checklist.
- **Portofolio:** simpan draft, feedback, dan revisi terpisah; isi empat skor 0–3 dengan asal penilai dan level target tugas. Speaking menyimpan referensi bukti, interaktivitas, rubrik, dan file audio lokal opsional. Histori seluruh sesi tersedia dari tautan portofolio di Progres. Self-check dan AI tetap ditampilkan, tetapi bukan penilaian manusia. Audio harus diunduh terpisah untuk cadangan; menghapus bukti juga menghapus audio terkait setelah konfirmasi.
- **Evaluasi mingguan:** di Progres atau langkah Review, catat hasil dari dua unit baru berbeda per skill listening/reading pada level eksplisit yang sama, tanpa bantuan. Rekomendasi memakai minggu terpilih dan minggu sebelumnya; pengulangan tidak mengganti hasil pertama. Output memerlukan dua tugas mandiri berbeda, dinilai manusia, minimal 8/12 tanpa aspek 0; speaking harus interaktif. Listening/reading memerlukan minimal 70% per unit. Satu skill lemah → fokus; dua atau lebih → ulang; bukti belum cukup → kumpulkan; semua cukup → pertimbangkan tantangan berikut. Tidak mengunci minggu atau menetapkan CEFR.
- **Level dan batas bukti:** per skill, evaluasi meninjau level eksplisit terbaru, tidak mencampur hasil lintas level. Sampel diagnosis lebih tinggi dapat menghasilkan saran mengumpulkan bukti baru; ini bukan pembatalan capaian sebelumnya. Level berbeda antarskill ditampilkan sebagai gap, bukan satu level diri. Semua hasil/identitas penilai dicatat pengguna dan tidak diverifikasi aplikasi.
- **Batas lokal:** maksimal 5.000 catatan per jenis hasil, waktu, speaking, dan review; 100 snapshot writing per sesi. Riwayat tidak digeser otomatis demi menjaga asal percobaan pertama. Ekspor arsip dan hapus data yang tersedia bila penuh. Browser dapat menolak penyimpanan lebih awal karena kuota; peringatan menjelaskan data yang belum tersimpan. Catatan review mingguan ditambah sebagai entri bertanggal, bukan ditimpa.
- Modul `src/learning.js` menormalisasi bukti manual dan menghasilkan saran; `src/quiz-tracking.js`, `src/study-time.js`, `src/portfolio.js`, `src/audio-store.js`, dan `src/evaluation-ui.js` menangani antarmuka serta penyimpanan lokal. Kunci progres lama dipertahankan; format versi 3 mempertahankan data versi 1/2 dan menambahkan `mastery` tanpa mengubah checklist menjadi kelulusan.

## Penguasaan: tes → submission → feedback → revisi

- **Review tiap minggu:** 104 soal jawaban singkat (empat per minggu), dengan pembahasan dan remedial setelah menjawab. Ambang kerja 3/4; seluruh percobaan disimpan. Pengulangan bukan materi baru atau tes CEFR.
- **Tugas transfer:** 26 tugas tulisan dan 26 tugas rekaman asli; checkpoint integratif baru pada minggu 4, 8, 12, 16, 20, 24, dan 26. Prompt, sumber akademik fiktif, serta rubrik berasal dari server, bukan instruksi yang dikirim siswa.
- **Status terpisah:** aktivitas/checklist, kiriman menunggu penilaian, perlu revisi, dan lulus sementara AI. Minggu memerlukan tes pemahaman dan kedua jenis karya; minggu gate juga memerlukan kedua karya fase. Nilai minimal 8/12 tanpa aspek 0 dan tanpa aspek yang tak dapat dinilai. Review manusia tetap catatan yang dilaporkan pengguna, bukan identitas yang diverifikasi aplikasi. Semua minggu tetap dapat dibuka.
- **Riwayat tidak ditimpa:** kiriman disimpan sebelum menghubungi AI. Kegagalan jaringan/provider mempertahankan teks dan audio lokal. **Coba nilai kiriman yang sama** memakai bukti asli, sedangkan feedback sukses ditambahkan sebagai snapshot terkait; revisi mengacu ke kiriman induk dan tidak dianggap bukti mandiri baru. Ekspor JSON berisi teks/feedback/referensi, bukan file audio. Unduh audio asli terpisah. Isian yang belum dikirim hanya bertahan pada sesi halaman.
- **Batas speaking:** teks saja tidak cukup. Bila hanya transkripsi tersedia, keterpahaman/kelancaran tidak diberi skor dan tugas belum lulus. Monolog atau simulasi pertanyaan sendiri bukan bukti interaksi spontan. AI dapat salah; checkpoint penting tetap membutuhkan penilai manusia.

### Latihan bicara langsung di langkah 3

Pada **Bicara & tulis** (hari 1–6), pilih **Mulai rekam**, izinkan mikrofon, lalu **Hentikan rekaman**. Putar audio untuk mendengarkan, centang persetujuan, lalu pilih **Minta koreksi rekaman**. Tidak ada pemilih berkas di latihan harian; tombol koreksi baru aktif setelah ada rekaman atau kiriman tersimpan untuk dicoba lagi. Token pelajar tetap diperlukan melalui **Koneksi penilaian AI**. Hasil terbaru langsung menampilkan transkrip, koreksi, alasan, dan langkah latihan berikut; **Latih ulang dari koreksi ini** membuka rekaman baru yang terhubung dengan kiriman sebelumnya. Ini alur rekam–koreksi, bukan percakapan suara real-time. Catatan/revisi, riwayat, dan arsip manual terlipat agar tidak menghalangi mikrofon.

Rekaman tidak dikirim otomatis. Memerlukan HTTPS/localhost dan browser dengan MediaRecorder. Bila mikrofon ditolak, izinkan melalui pengaturan browser dan coba lagi. Batas 5 menit / 10 MiB; timer dapat terlambat saat tab ditangguhkan. Berpindah halaman membatalkan take aktif dan melepaskan mikrofon.

Take selesai disimpan lokal di IndexedDB per minggu/hari; take baru mengganti draft lokal, bukan kiriman terdahulu. JSON ekspor tidak memuat Blob audio: unduh audio terpisah. Gemini melalui backend 9router mentranskripsikan audio, kemudian mengoreksi grammar dalam bahasa Indonesia dengan kutipan dan perbaikan. Transkrip dapat salah; pronunciation, keterpahaman, kelancaran, dan interaksi tidak diberi skor berdasarkan teks saja. Latihan harian beserta revisinya dipisahkan dari tes mingguan/checkpoint; tidak menaikkan status penguasaan.

`POST /api/assess` menerima `stage: "practice"` hanya untuk `kind: "speaking"` dengan `day` integer 1–6 dan `taskPrompt` yang sama persis dengan tugas kanonis. Ini pengaman klien lama, bukan izin mengganti prompt: tujuan, sumber, dan instruksi penilai tetap diambil dari `dailyLesson(week, day)` di server. Bukti baru menyimpan salinan tugas; arsip lama tetap dapat dibaca/diunduh tetapi tidak dinilai ulang terhadap tugas baru. Identitas bukti `wN-dD-practice-speaking`; kiriman, feedback, dan hubungan revisinya append-only. Draft mikrofon baru memakai namespace `daily-v1` agar take lama tidak terpilih untuk tugas baru. Buffer menulis menyimpan tugasnya; buffer lama tanpa asal tugas dipertahankan dengan peringatan dan kolom tugas kosong, bukan otomatis dianggap jawaban baru.

### Backend pribadi

`server/assessment.mjs` adalah server Node tanpa dependency tambahan. Endpoint `POST /api/assess` memerlukan bearer token pelajar minimal 32 karakter, origin yang diizinkan, JSON terbatas, maksimal dua penilaian bersamaan dan 60 request per jam. Input teks dibatasi 20.000 karakter, audio 10 MiB. Rubrik/tugas kanonis diambil dari `src/mastery-content.js`. API key provider tidak boleh dimasukkan ke frontend. Token pelajar hanya disimpan di sessionStorage tab dan tidak diekspor. Backend tidak menyimpan isi submission; provider upstream dapat memiliki kebijakan retensi sendiri.

Deployment VPS berada di `/opt/englishcourse`: project `englishcourse` menjalankan `englishcourse-assessment-1`, project `englishcourse-router` menjalankan `englishcourse-router-router-1`. Salin `server/compose.yml` menjadi `compose.yml`, `server/router.compose.yml` menjadi `router.compose.yml`, serta `server/assessment.mjs`, `src/mastery-content.js`, `src/course.js`, `src/course-foundations.js`, `src/course-workplace.js`, dan `src/course-academic.js` ke subdirektori masing-masing. Backend non-root/read-only memakai jaringan ingress bersama dan jaringan privat `englishcourse_router`; router hanya berada di jaringan privat, tanpa port host/dashboard publik. Secret `.env` mode 600: `LEARNER_TOKEN`, `ROUTER_URL=http://router:20128/v1`, `ROUTER_API_KEY` khusus VPS, `TEXT_MODEL=ag/gemini-3-flash`, `AUDIO_MODEL=ag/gemini-3-flash`, dan `ALLOWED_ORIGINS`. Token pelajar tetap sama; API key router tidak masuk frontend/git. Jalankan router dahulu dengan `sudo docker compose --project-directory /opt/englishcourse -p englishcourse-router -f /opt/englishcourse/router.compose.yml up -d`, lalu backend dengan `sudo docker compose --project-directory /opt/englishcourse -p englishcourse up -d`. Perubahan environment memerlukan recreate container terkait; perubahan modul server memerlukan restart assessment, bukan restart ingress bersama.

Untuk pembaruan paket harian, backend juga memerlukan `src/daily-course.js`, `src/daily-foundations.js`, `src/daily-workplace.js`, dan `src/daily-academic.js` bersama dependensi course evaluasi. Salin seluruh modul sebelum restart assessment agar prompt server sama dengan website. Jangan restart router/ingress bersama untuk perubahan materi.

HTTPS: `https://englishcourse.43-133-141-109.sslip.io/api/health`. **HTTP 200 health hanya membuktikan proses hidup, bukan provider AI berhasil.** Host baru diproksikan Caddy bersama; cadangan ingress `/opt/cold-calling/Caddyfile.before-englishcourse`.
